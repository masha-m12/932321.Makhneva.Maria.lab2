# 932321.Makhneva.Maria.lab2

## Лабораторная работа №2. Базовые и продвинутые возможности CSS.

### Описание работы

Оформлена HTML-страница «О себе» из ЛР №1 с помощью внешнего CSS-файла (style.css). Реализованы селекторы, типографика, работа с цветом, отступами, позиционированием и псевдоклассами. Дополнительно реализована подсветка активной секции при скролле.

### Реализация

Основной стиль вынесен во внешний файл style.css.  
Один элемент с inline-стилем — <aside>).  
Одно правило во внутреннем блоке <style> — стили для textarea.  
В :root заданы переменные для цветов и шрифта.  

**Позиционирование**
*static* — header (задано явно).  
*relative* — .project (карточка проекта).  
*absolute* — .favorite (иконка «Избранное» в углу карточки проекта).  

**Псевдоклассы состояний:** :hover, :active, :focus, :visited.
